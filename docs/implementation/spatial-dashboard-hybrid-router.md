# Spatial dashboard and hybrid router implementation

Implemented on the existing native Apple dashboard branch. The approved Mac/iPad-first plan retains SceneKit, existing Terra contracts and command safety paths. User amendment: an explicit all-interface LAN bind and Bonjour discovery coexist with loopback and Tailscale modes; no paid hosting is provisioned.

Verified: 35 Rust tests (including managed-router telemetry, correlated goal acknowledgment, and no replay after reconnect); 27 native Mac tests (including camera orbit round trip, selection/frame draft invalidation, delayed refresh rejection, stale/unknown positioning and existing command authority tests); Mac and arm64 iPhone/iPad builds. Generated Info.plist contains the Bonjour service declaration. Local router ownership and port collision paths are covered by executable tests. The standalone macOS router's CLI was exercised. The disconnected native scene was inspected and captured through computer use.

Ruling: preserve the renderer and working authority/control backend; replace presentation incrementally rather than discard tested contracts. Goals are drawn as target lines, never inferred planned trajectories. New session generations fence refreshes and invalidate local interaction state even when fleet IDs remain identical. Bonjour discovery advertises only app-owned Mac LAN routers; standalone hosts use an explicit address.

Remaining physical verification: real iPad touch/local-network permission and Bonjour resolution across devices, Tailscale/cloud-host connectivity, real rover command behavior, reduced-motion preference on devices, Vision Pro/Quest clients (later release). iPad build is unsigned and requires an Apple signing team for installation. Linux router container build, wildcard listener, and a real native Zenoh connection through its published port passed. Cross-device LAN reachability remains a physical check.

Forest-delay amendment: high-level supervision expires at 90 seconds; goal acknowledgment timeout is 150 seconds. Cached authority/hardware/position under the supervision window permit waypoint preparation, including the native switch to waypoint mode. Manual driving and arming keep their strict freshness checks. Discard, selection changes, new drafts, disconnect and fleet stop invalidate pending waypoint preparation before dispatch. Rust synthetic-age and Swift delayed-ack regression tests cover these boundaries.
